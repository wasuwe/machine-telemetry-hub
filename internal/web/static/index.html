Use the API

Read the same live data as the dashboard from your own code: machine state and OEE, and the raw readings stored by the IoT sensors. The API is read-only and returns JSON.

Base URL
/api/v1
Auth
API key in the header Authorization: Bearer <key> (or X-API-Key: <key>)
Errors
application/problem+json (RFC 9457) with a code you can switch on
Rate limit
Per key, per minute. Every response says how much is left in RateLimit-Remaining
CORS
Open to any origin, so you can call it from a browser page
